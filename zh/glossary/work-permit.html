工作许可

“外国人如何取得土耳其工作许可？”

简要回答

A 工作许可（Çalışma İzni） 是土耳其向外国人授予的法律授权，允许其在境内合法工作。它受第6735号《国际劳动力法》规管，并由家庭、劳动及社会服务部评估。关键在于，有效工作许可同时具有居留许可的效力。

法律框架及《国际劳动力法》

随着 第6735号《国际劳动力法》（Uluslararası İşgücü Kanunu - UİK）出台，土耳其对外国人就业的制度进行了重大重构，取代了原第4817号法律。新立法旨在吸引合格外籍劳动力、简化行政程序，并根据土耳其经济及行业需求有效管理移民。

关键概念及权利

  • 取得许可的义务： 除国际条约或特定法律条文规定豁免外，外国人必须取得工作许可， 然后才能 在土耳其开始受雇或独立工作。
  • 替代居留许可： 根据法律，经批准的工作许可或“工作许可豁免”文件直接具有居留许可的效力。因此，外国人无需另行申请居留许可。
  • 评估标准： 申请根据总体经济形势、劳动力市场发展、行业变化及外国人的具体资质进行评估。

工作许可类型

土耳其法律将工作许可划分为若干不同类型，适应不同就业方式及外国人身份：

许可类型 说明及条件
定期（Süreli）工作许可 首次授予的最长期限为 一年 ，与特定工作场所、雇主及职业绑定。为同一雇主工作时，可延长至两年，此后延长至三年。
无期限（Süresiz）工作许可 授予持有长期居留许可，或已在土耳其连续合法居住 / 工作至少 八年的外国人。它不将员工绑定于特定雇主。
独立（Bağımsız）工作许可 授予以自身名义工作（例如自雇专业人士、企业所有者），且符合对土耳其经济贡献相关特定标准的外国人。
例外（İstisnai）工作许可 对特定群体（例如高资质专业人士、关键人员、欧盟公民、土耳其血统人士或难民），按更灵活的条件签发。
绿松石卡（Turkuaz Kart） 向高资质投资者、科学家、艺术家或运动员授予无期限工作及居留权的特殊身份，设有3年过渡期。

申请程序

工作许可申请可通过两种主要渠道提出：

  • 境内申请（Yurt İçinden）： 如果外国人持有有效期至少6个月的土耳其居留许可，雇主可通过该部的在线系统直接申请。
  • 境外申请（Yurt Dışından）： 如果外国人未持有居留许可，必须向其国籍国 / 居住国的土耳其大使馆 / 领事馆申请工作签证。申请人将取得16位参考编号，土耳其雇主随后使用该编号在线完成申请。

关键申请指引

  • 100%数字化流程： 所有申请均通过e-Devlet系统使用合格电子签名以电子方式处理。不应向总局邮寄纸质表格、申请书或文件。
  • 电子签名要求： 雇主的SGK（社会保障）e-bildirge用户必须持有自己的电子签名，才能在系统中登记工作场所。切勿共享您的e-Devlet或电子签名密码。
  • 劳动合同： 必须拟订正式劳动合同，并由雇主及外籍员工双方签署。
  • 生物识别照片： 上传照片必须在最近6个月内拍摄（白色背景、正面、可清晰识别），并按正确比例调整，因为照片将直接印制在实体工作许可卡上。
  • 联系信息： 确保申请所提供的电子邮箱地址直接属于申请人本人（对家政工作人员尤其关键）。使用第三方邮箱往往导致漏收通知及不利结果。
  • 获批后义务： 收到工作许可后，雇主必须完成SGK（社会保障）登记，期限为 30天.
  • 终止： 劳动关系结束后，雇主必须及时通知SGK，并在该部在线系统中注销工作许可。

禁止从事的职业及合同效力

根据土耳其法律，某些职业严格保留给土耳其公民，禁止外国人从事（例如牙科、药剂、兽医、法律执业 / 律师、公证、报关代理）。为外国人从事这些禁止职业而订立的劳动合同，依法 无效（hükümsüz）.

此外，如果外国人受雇从事获准职业，但 未 取得强制要求的工作许可，劳动合同通常被视为无效；不过，根据保护员工原则，雇主仍须对实际工作期间的工资及社会保障缴费承担责任。

非法用工的处罚

未持有效工作许可雇用外籍员工（kaçak yabancı istihdamı），将引发严重的行政及刑事后果。劳动监察员和社会保障审计人员会定期检查。违规将导致高额 行政罚款（İdari Para Cezaları） ，对雇主及非法工作的外国人双方处以罚款。多数情况下，未经授权工作的外国人还会被立即驱逐出境（sınır dışı）。

常见问题（FAQ）

外国人如何取得土耳其工作许可?

工作许可由家庭、劳动及社会服务部评估并签发。申请可在境内提出（如持有有效居留许可），也可通过土耳其领事馆 / 大使馆从境外提出。

土耳其工作许可能否替代居留许可？

可以。根据土耳其法律，有效工作许可或工作许可豁免明确替代居留许可（İkamet İzni），允许外国人在许可有效期内合法居住于土耳其。

无证工作会受到哪些处罚？

未持有效许可工作，将使雇主及外籍员工双方受到高额行政罚款，且通常导致该外籍员工被驱逐出境。
